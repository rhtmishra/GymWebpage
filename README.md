💪 GymWebpage
A responsive and modern landing page for a fitness or gym business, built with HTML, CSS, and JavaScript. This project showcases a clean UI with sections for services, trainers, pricing, testimonials, and contact information.

🔧 Features
Fully responsive design for all devices

Hero section with call-to-action

About and Services section

Trainer profiles with images

Pricing plans

Testimonials carousel

Contact form and footer

🛠️ Tech Stack
HTML5

CSS3 (including Flexbox and Grid)

JavaScript (vanilla)


📁 How to Use
Clone the repo
git clone https://github.com/rhtmishra/GymWebpage.git

Open index.html in your browser
